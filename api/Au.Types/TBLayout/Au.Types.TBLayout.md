## Fields

### `HorizontalWrap`

Default layout. Buttons are in single row. Wrapped when exceeds maximal row width. More rows can be added with `Au.toolbar.Group`.

### `Vertical`

Buttons are in single column, like in a popup menu. Separators are horizontal.
